# Трекер трекеров

Тёмное, адаптивное PWA-приложение для отметки привычек и дел по дням.
Каждый трекер можно отметить ✓ (сделал) или ✕ (не сделал), указать время
(«во сколько») и посмотреть историю за 3 недели с днями недели (Пн–Вс).
Видно, когда именно был добавлен трекер (дата и время). Полностью работает
офлайн после первого открытия — данные хранятся локально в браузере
(localStorage), ничего не уходит на сервер.

Новое в этой версии:
- Полоса недели наверху (Пн–Вс), сегодняшний день подсвечен золотым
- История трекера показывает дни недели, а не просто числа
- Видно дату и время, когда трекер был создан («Добавлен: 14 сентября в 20:06»)
- Тап по названию трекера открывает редактирование (можно поменять
  название и время)
- Трекеры без отметки за сегодня показываются выше отмеченных — сразу видно,
  что осталось сделать
- Кнопка «Установить» появляется сама в заголовке, если Chrome на Android
  готов установить приложение — не нужно лезть в меню
- Иконка приложения — чёрная, с золотой галочкой

## Файлы
- `index.html` — страница приложения
- `style.css` — стили (тёмная тема, адаптивная вёрстка)
- `app.js` — вся логика (хранение, отметки, стрики)
- `manifest.json` — манифест PWA
- `sw.js` — service worker для офлайн-работы
- `icons/` — иконки приложения

## Как запустить локально (для проверки)
PWA требует, чтобы файлы отдавались через http(s), а не открывались как
`file://`. Проще всего поднять локальный сервер:

```bash
cd tracker
python3 -m http.server 8080
```

Затем открой `http://localhost:8080` в браузере.

## Как установить на Android (после того как сайт где-то опубликован)
PWA можно установить на телефон только с реального хостинга по **https**
(на локальном `http://localhost` установка на Android обычно не работает —
Android требует https, кроме localhost на десктопе).

Бесплатные варианты, куда можно закинуть эту папку:
- **GitHub Pages** — залить папку в репозиторий, включить Pages в настройках.
- **Netlify / Vercel** — просто перетащить папку на их сайт (drag-and-drop deploy).
- **Cloudflare Pages** — аналогично, загрузка папки без лишних настроек.

После публикации:
1. Открой ссылку на сайт в Chrome на Android.
2. Открой меню (⋮) → **«Установить приложение»** (или Chrome сам покажет
   баннер с предложением установить).
3. Приложение появится на рабочем экране как обычное приложение,
   со своей иконкой, без адресной строки браузера.

## Как добавить свой трекер
Нажми круглую кнопку «+» в правом нижнем углу, впиши название
(например «Изучаю Python — анализ») и, если нужно, время. Дальше просто
нажимай ✓ или ✕ каждый день. Нажатие на стрелочку ▾ раскрывает историю
за последние 14 дней.
